# P5 对话气泡

TauriTavern / SillyTavern 浏览器端 UI 扩展。把 AI 回复里的引号台词渲染成 P5 风格倾斜气泡，另有论坛体卡片和弹幕条。只改显示层 DOM，不改聊天记录。

逻辑与配色移植自我的阅读 App 段落脚本「奶茶のP5聚合(0904)」。

## 功能

- 对话气泡：识别 `“”` `""` `「」` `『』` 里的台词，左右交替，长台词按句末标点拆分
- 论坛体（默认关）：整行写成 `昵称：内容`
- 弹幕（默认关）：整行被 `【】` `[]` `［］` 包住
- 10 套配色：日间 P5柔和 / 温润奶咖 / 冷萃青 / 樱粉手账 / 绿森林；夜间 P5暗黑 / 夜间Storm / Latte深咖 / 复古红蓝 / 纯粹黑灰
- 开关：总开关、对当前角色/群聊停用、处理用户消息、严格模式（跳过卡片自带 HTML 容器）、首个气泡方向、拆分字数、字号
- 气泡宽度：按消息区百分比设定，0 = 按内容自适应；输入即生效，不用重新渲染
- 弹幕切字：单条超过 N 字后在标点处断开，无标点则按 1.5N 硬切，避免长句撑破弹幕框
- 魔棒菜单：一个日/夜图标 + 当前主题名，整项点按切换（TT 移动端菜单里原生下拉弹不出来，所以只做切换）

## 安装

把仓库内容放到 `data/extensions/third-party/p5-bubble/`，重启后在扩展管理里启用。

格式要求世界书 `P5气泡格式.json` 放到 `data/default-user/worlds/`，在需要的卡里挂上。

## 测试
